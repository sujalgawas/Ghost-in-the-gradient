# Prompt: Build & Deploy the Tiny-Aya Structured JSON Evaluation & Playground Web App on Vercel

You are an expert full-stack Next.js (App Router), TypeScript, Tailwind CSS, and AI/ML UI engineer. Build a polished, production-ready web application designed to be deployed on **Vercel** for evaluating and showcasing three schema-conditioned JSON extraction models from our Lexsi Labs AI Safety & Alignment Hackathon submission:

1. **Base**: `CohereLabs/tiny-aya-global` (vanilla 3.35B baseline)
2. **SFT v2**: `monson2002/tiny-aya-sft-v2-adapter` (LoRA SFT adapter on Tiny Aya)
3. **DPO**: `monson2002/tiny-aya-sft-v2-dpo-adapter` (LoRA DPO-aligned adapter on Tiny Aya)

---

## 1. Tech Stack & Vercel Deployment Architecture

- **Framework**: Next.js 14+ (App Router, TypeScript)
- **Styling & UI**: Tailwind CSS + `lucide-react` icons + clean dark/light developer-grade aesthetic (slate/zinc surfaces, emerald/cyan accents for passing metrics, amber/rose for hallucinations/errors)
- **Charts**: `recharts` (responsive bar charts, radar chart, domain breakdown chart)
- **PDF Parsing (Client-Side)**: `pdfjs-dist` (so users can drop a PDF in the browser and extract its text cleanly without needing a heavy Node PDF binary on Vercel Serverless)
- **Schema Validation**: `ajv` (for real-time client/server `schema_valid` checking against the user's JSON Schema)
- **Vercel Server Proxy (`app/api/infer/route.ts`)**:
  - Reads `HF_INFERENCE_URL` (our Hugging Face Space / Inference Endpoint URL backed by our $20 HF credits on an `Nvidia T4 Small` `$0.40/hr` instance with 15-min Auto-Sleep) and `HF_TOKEN` from **Vercel Environment Variables** (never exposed to the client).
  - Accepts `{ model: "base" | "sftv2" | "dpo" | "all", document: string, schema: object, output_format: "json" }`.
  - If `model === "all"`, fans out or sequentially requests all 3 models from the HF backend and returns `{ predictions: { base, sftv2, dpo }, latencies_ms }`.
  - Includes graceful error handling if the HF Space is waking from Auto-Sleep (returns a `503` / `waking_up` status so the UI displays a friendly "Waking up T4 GPU (~20s)..." banner and auto-retries).

## 3. Hugging Face $20 Credit Backend Contract (Expected by `/api/infer`)

Assume our Hugging Face Space (`Nvidia T4 Small`, `$0.40/hr` with 15-min Auto-Sleep) loads `CohereLabs/tiny-aya-global` once in `fp16`/`4-bit` and switches adapters in memory (`< 1 ms`) between `base` (`disable_adapter()`), `sftv2` (`monson2002/tiny-aya-sft-v2-adapter`), and `dpo` (`monson2002/tiny-aya-sft-v2-dpo-adapter`).

Implement `app/api/infer/route.ts` to `POST` to `${process.env.HF_INFERENCE_URL}/extract` with:
- Header: `Authorization: Bearer ${process.env.HF_TOKEN}`
- Body: `{ "model": "base" | "sftv2" | "dpo", "document": "...", "schema": { ... }, "output_format": "json" }`
- Response: `{ "model": "...", "raw_output": "...", "parsed_json": { ... } | null, "latency_ms": 840 }`
